Confidence: 0.6

When content is contaminated by external references, the user demands a clean regeneration from scratch using only the skill + the actual source ticket (explicitly: "do not take any reference from the other skills or any other source. Do it again") — no other skills, no asset PDFs, no prior documents — and expects the final deliverables to be verified clean of the disallowed references. Confidence: 0.9
- Expects every claim in deliverables to be traceable to actual sources — the user will challenge ungrounded content (e.g., asked why a product was named "VWO (Wingify)" when they never wrote it).
